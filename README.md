# Система за проследяване на доставки (Куриерска фирма)

## Описание на проекта
Този софтуерен продукт е разработен като курсов проект по дисциплината "Информационни системи". Системата управлява информация за пратки, изпращачи, получатели и текущ статус, като оптимизира логистиката чрез централизиран контрол. Позволява на клиентите бързо да проследяват пратките си по номер (товарителница), а на служителите – да администрират процеса чрез вътрешен панел.

## Използвани технологии
* **Backend:** Node.js с Express.js (RESTful API)
* **Database:** MySQL
* **Frontend:** HTML, CSS, Vanilla JavaScript (Уеб форма)
* **Инструменти:** Postman (за тестване на API), Git (за контрол на версиите)

## Стъпки за инсталация на чиста среда
1. Клонирайте репозиторито локално:
   `git clone [линк_към_вашето_репо]`
2. Влезте в папката на приложението:
   `cd app`
3. Инсталирайте нужните зависимости:
   `npm install`
4. Създайте базата данни:
   * Отворете MySQL сървъра (напр. XAMPP или MySQL Workbench).
   * Изпълнете скрипта от `database/init.sql`, за да създадете таблиците и тестовите данни.
5. Конфигурирайте променливите на средата:
   * Копирайте файла `.env.example` и го преименувайте на `.env`.
   * Въведете вашите данни за достъп до MySQL (потребител, парола, порт).

## Стартиране на системата
За да стартирате сървъра, изпълнете следната команда в папката `app`:
`npm start`
Сървърът ще се стартира на `http://localhost:3000`.

## Тестови потребители и данни
За демонстрация на системата са заложени следните фиктивни данни:
* **Примерна пратка за проследяване:** `TRK987654321`
* **Вход за служители:** 
  * Потребител: `admin`
  * Парола: `123456`
* **Примерни статуси:** "Приета в офис София-Център", "Транзит през Разпределителен център Пловдив", "В разнос - куриер Иван".
